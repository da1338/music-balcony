# 江上城堡项目 · 方案网页

本仓库承载江上城堡相关方案网页。当前首页为「AI 仿真歌姬落地执行方案」，历史方案完整保留在版本目录中。

## 在线查看

- **当前方案**：<https://da1338.github.io/music-balcony/>
- **版本历史**：<https://da1338.github.io/music-balcony/versions/>

## 目录结构

```
index.html                          当前方案：AI 仿真歌姬落地执行方案（首页）
versions/index.html                 版本历史总入口
versions/2026-10-12_音乐阳台/       2026-10-12 音乐阳台历史方案（含汇报页、图文合集、图片与 STL）
favicon.png                         站点图标
```

## 版本管理约定

- 首页 `index.html` 永远指向当前方案。
- 每次更新方案：先在 `versions/` 下新建以日期命名的目录，把旧方案整套移入并加存档标记（`noindex` + 顶部存档提示 + 双向链接），再用新方案替换首页。
- `versions/index.html` 用一张卡片对应一个版本；新增历史版本时复制一张卡片、改日期与链接即可。
- 历史页面不进入搜索引擎索引，但可通过版本历史入口直接打开。
