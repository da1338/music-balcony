## 这个项目是什么

在城堡右侧翼的二层阳台上，放两只**会唱歌、会动**的卡通熊：

- **白熊船长** 持麦演唱，嘴会开合、眼睛会看观众、举麦的手会随节奏抬起
- **棕熊海盗** 怀抱吉他弹唱，拨弦手、按弦手、嘴、眼都会动

每天定时表演，也可由楼下观众的声音触发。熊的身体内部完全看不到机械——**观众看到的就是两只活的玩偶在演出**。

### 三条核心设计决定

| | 决定 | 为什么 |
|---|---|---|
| 01 | **外皮用泡沫雕刻**，不用实体模具 | 重量轻一半以上，阳台楼板负担小；后期改造型只需重雕那一块 |
| 02 | **舵机／减速电机驱动，只做手、嘴、眼三处** | 观众在 15 米外只看得见这三处；每多一个动作就多一个故障点和一份成本 |
| 03 | **电机竖装、向下拉，配机械硬限位＋自锁刹车** | 负载是「压」不是「悬」，寿命长；户外风吹加重载，软限位一定会烧驱动，停电必须当场锁死 |
